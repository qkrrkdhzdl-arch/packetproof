Packetproof

Seal what you submit.

100% 로컬 · 업로드 없음 GitHub

접수 사이트는 제출한 뒤에 알려 줍니다. 파일이 빠졌다고, 용량이 넘었다고, 같은 서류를 두 번 올렸다고. Packetproof는 보내기 전에 폴더 하나를 검사합니다 — 그리고 봉인(seal)해서, 무엇을 언제 보냈는지 SHA-256으로 남깁니다.

1 · 무엇을 내야 하나

공고문에 적힌 제출물을 그대로 옮겨 적으세요. 항목 이름에 들어 있는 단어로 파일을 찾습니다.

항목필수형식최대

2 · 무엇을 보내려 하나

폴더 · 파일 · ZIP을 여기에 끌어다 놓거나 눌러서 고르세요. 파일은 이 페이지를 떠나지 않습니다.

3 · 보내도 되나

검사 대기
파일을 넣고 검사를 한 번 실행하면 봉인할 수 있습니다.

Packetproof는 정적 웹 앱입니다 — 서버도, 계정도, 업로드도 없습니다. ZIP은 브라우저의 DecompressionStream으로 풀고, 해시는 crypto.subtle로 계산하며, 문서(docx · xlsx · pptx · hwpx)는 ZIP+XML을 직접 읽습니다.
